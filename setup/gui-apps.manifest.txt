# GUI apps to install by hand on a new desktop (Ubuntu or Fedora, GNOME); the
# setup scripts don't install them. One app per line:
#   Name (homepage) — what it is
# Install each the way its homepage recommends for the distro: distro repo,
# Flathub, the vendor's apt/rpm repo or package, or an AppImage. AppImages
# need FUSE 2 (libfuse2t64 on Ubuntu, fuse-libs on Fedora). Apps that ship
# with a stock GNOME desktop (Firefox, ...) are left out.
