GUI apps to install by hand on a new Ubuntu desktop
===================================================

These GUI apps are on my main machine (Ubuntu 26.04, GNOME) but
setup/ubuntu.sh does not install them. Apps that ship with a stock Ubuntu
desktop are left out. Snapshot taken 2026-10-03.

Vendor apt repos: add the repo, then sudo apt install <package>
----------------------------------------------------------------
Get each signing key from the vendor's Linux install page. Some vendor
.debs (Chrome, Slack) add their repo themselves on first install.

Flatpak
-------
sudo apt install flatpak
flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak install flathub it.mijorus.gearlever

it.mijorus.gearlever            Gear Lever, manages the AppImages below


AppImages (in ~/AppImages, added to the app menu with Gear Lever)
-----------------------------------------------------------------
Need FUSE 2 first: sudo apt install libfuse2t64

Bruno                           API client          https://www.usebruno.com/downloads
Dadroit JSON Viewer             JSON viewer         https://dadroit.com
Prettify                        JSON/YAML/CSV/XML/Mermaid viewer (source not recorded)


Other installers
----------------
Zed (editor)
    curl -f https://zed.dev/install.sh | sh     # installs to ~/.local/zed.app
SmartGit (Git client)
    Download the Linux tarball from https://www.syntevo.com/smartgit/download/,
    extract it to /opt/smartgit, then run /opt/smartgit/bin/add-menuitem.sh
WhatsApp Web (Chrome web app)
    Open https://web.whatsapp.com in Chrome and use "Install page as app".
